# SoundCloud Likes Viewer

Browse, search, and preview all your SoundCloud liked tracks in a local web app.

## Usage

No install needed — just Node.js.

\`\`\`
node soundcloud_likes.js <your-username>
\`\`\`

Opens a browser at http://localhost:3000 with your full likes library.

## Features
- Infinite scroll through all likes
- Embedded SoundCloud player
- BPM, key & genre tags (when available)
- Search by title or artist
- Export to CSV or plain text links
